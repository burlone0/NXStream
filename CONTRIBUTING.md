# Contributing

Contributions are welcome through issues and pull requests on this repository.

## License of contributions

By submitting a contribution you agree that it is licensed to the author under
terms that allow the author to include it in NXStream and to relicense it, and
you confirm that you have the right to submit it.

## Rules

- Write code and text in English.
- Keep the code organized and in the right place: `switch/` for the console side, `pc/` for the viewer.
- Every viewer feature must exist on both Windows and Linux.
